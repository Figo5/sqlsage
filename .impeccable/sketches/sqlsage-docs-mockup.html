-- Getting started

sqlsage connects to your existing database and turns raw queries into something you can actually read back later — versioned, annotated, and searchable.

Most tools ask you to leave the terminal to understand your data. sqlsage doesn't. Every session you run stays exactly where you left it: a query, its result, and whatever note you attached to it, saved in order.

Install the CLI, point it at a connection string, and you're reading results in under a minute. No dashboard to configure first.

session — events
sqlsage=# SELECT id, name, ts FROM events ORDER BY ts DESC LIMIT 3;
idnamets
8841session_start14:22:07
8840query_run14:21:52
8839connect14:21:40
(3 rows)
sqlsage=#

Results aren't thrown away when the session ends. Reference an earlier query with \r 8840 and it reopens exactly as it ran, result set included.
