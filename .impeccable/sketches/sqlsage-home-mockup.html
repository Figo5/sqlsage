-- what it does

correctness
Correctness before speed
A query that silently returns the wrong rows matters more than one that's merely slow — wrong-result risks are flagged first.
explain
Plain-English explanations
Result grain, execution shape, and risk — described in words, with the exact SQL and column behind each finding.
evidence
Honest evidence labels
Every claim is predicted, plan-observed, measured, or unverified. Nothing over-promises.
offline
Works completely offline
Analyze with just schema or catalog metadata. A database connection is optional, and never required.
actionable
Explicit change sets
Conservative index recommendations and rewrites — never executed silently, always reviewable.
json
Machine-readable output
An evidence bundle you can replay and compare across captures, in text, markdown, or JSON.
